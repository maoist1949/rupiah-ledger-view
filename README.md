# Rupiah 账本 · 手机只读版

此仓库只托管静态查看页面和加密快照，不包含电脑原始账本或普通 JSON/CSV 备份。

## 更新记录

1. 电脑账本 → 备份 → 手机只读快照。
2. 输入并确认查看密码（至少 3 个字符，建议 12 位以上），点击“导出手机只读快照”。123 等短密码很容易被猜到。
3. 本地启动版的文件保存在项目 `phone-site/phone-ledger.json`；其他环境会下载文件（不要带 `(1)`）。只把这个加密文件上传到本仓库根目录，替换同名旧文件并提交。
4. 等待 GitHub Pages 发布完成，手机打开网站 → “锁定 / 刷新” → 输入查看密码。

不要上传 `data/ledger.json`、每日备份、普通导出文件、密码或其他私人文件。
密码不会存入快照，也不会发送给服务器；请使用不重复的长密码，自行保管。

这是手动更新的只读快照。手机可查看、搜索、筛选和分析，但不能修改记录。刷新或锁定后需要重新解锁。
加密算法：PBKDF2-SHA256（600,000 次）和 AES-256-GCM，每次导出使用随机盐和 IV。

GitHub Pages 设置：Settings → Pages → Deploy from a branch → main → /(root)。
